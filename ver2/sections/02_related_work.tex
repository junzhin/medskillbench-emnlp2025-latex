\section{Related Work}
\label{sec:related_work}

\subsection{Agent Skills and Skill Benchmarks}
\label{sec:rw_skills}

Skills extend language-model agents with reusable procedural knowledge: task descriptions, invocation conditions, parameter schemas, and multi-step workflows.
\citet{skillsbench2026} introduce \textsc{SkillsBench}, the first paired benchmark asking whether curated skills actually improve downstream task success.
Across 86~tasks in 11~domains, curated skills raise pass rates by 16.2~percentage points on average, with the medical domain showing the largest gain (+51.9~pp), while self-generated skills provide near-zero benefit.
\citet{skillnet2026} shift attention from task uplift to \emph{skill infrastructure}, scaling to 200K+ skills and proposing multi-dimensional static assessment along Safety, Completeness, Executability, Maintainability, and Cost-awareness.

These works establish that skills matter and that skill quality is an infrastructure problem rather than a pure prompting problem.
However, they still stop short of the interface layer that matters for deployment: \textsc{SkillsBench} measures task-level delta, not whether a specific skill specification was actually consulted and followed, while \textsc{SkillNet} evaluates skill assets largely through static quality analysis and repository organization.
\medskillbench bridges this gap by evaluating 1,462~medical skills (917~Tier-A) at the execution level, quantifying the \rbu gap between reading a \skillmd and correctly grounding it into action.

\subsection{Medical and Biomedical Agent Benchmarks}
\label{sec:rw_medical_bench}

Recent medical and biomedical benchmarks have diversified the evaluation surface for language-model agents.
\citet{medagentbench2025} present \textsc{MedAgentBench}, comprising 300~FHIR-compliant EHR tasks that test interactive clinical actions, while \citet{healthbench2025} release \textsc{HealthBench} with 5,000~multi-turn health dialogues scored by physician-authored rubrics.
In biomedical research, \citet{labbench2024} propose \textsc{LAB-Bench}, covering 2,400+~practical biology research questions, and \citet{labbench22026} extend this line with \textsc{LABBench2}, emphasizing more realistic research-task distributions.
\citet{medagentsbench2025} further target difficult medical reasoning by aggregating seven established datasets into a unified benchmark for modern thinking models and agent frameworks.
\citet{hle2025} introduce the expert-level \textsc{Humanity's Last Exam} (HLE), whose Biomedicine subset---together with \textsc{LAB-Bench}---has become a standard downstream testbed for biomedical agents \citep{stella2025,biomni2025}.
Interactive tool-use benchmarks such as $\tau$-bench \citep{taubench2024} and \textsc{ToolSandbox} \citep{toolsandbox2024} further formalize stateful, multi-turn evaluation with programmatic verification, while \citet{medagentgym2025} frame medical agent training as reinforcement learning over clinical environments.

These benchmarks establish task difficulty, external validity, and realistic interaction structure.
But they still assess \emph{task-level} success: did the agent solve the problem?
\medskillbench operates at a complementary \emph{skill level}: given a specific \skillmd, did the agent read it, invoke it, and follow it faithfully?

\subsection{Tool-Augmented Medical and Biomedical Agents}
\label{sec:rw_medical_agents}

Recent systems show that broad medical action spaces can materially improve end-to-end performance when agents can retrieve and execute specialized tools.
\citet{reflectool2025} introduce \textsc{ReflecTool} together with ClinicalAgentBench (CAB), emphasizing reflection-aware tool use across 18~clinical tasks.
In biomedical research, \citet{stella2025} and \citet{biomni2025} push further toward tool-rich agent systems: \textsc{STELLA} couples multi-agent planning with self-evolving templates and tool growth, while \textsc{Biomni} centers a large unified biomedical action space spanning databases, software tools, and analysis routines.
These systems make the practical case that curated tools and skills matter.
However, they treat the available tool inventory as a \emph{system-level resource} and evaluate the agent as a whole.
They do not isolate whether a particular authored skill specification was actually consulted, correctly interpreted, and faithfully executed.
\medskillbench targets exactly this interface layer between skill specification and grounded execution.
This perspective also complements generic tool-description optimization methods \citep{easytool2024,play2prompt2025,tracefree2026}, which improve documentation quality but do not benchmark execution fidelity of full medical skill specifications.
